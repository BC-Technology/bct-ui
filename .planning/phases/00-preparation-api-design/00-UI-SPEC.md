## Phase Scope Note

Phase 0 is a **documentation and CSS authoring phase**. No user-facing React components are built. The deliverables are:

1. `00-API-SPEC.md` — planning artifact documenting slot vocabulary, icon props, ref forwarding, MenuItem union, renderItem pattern
2. Token audit section in `00-API-SPEC.md` — confirming CSS variable coverage for all 37 target components
3. New animation class families stubbed into `packages/ui/src/assets/tokens/index.css`

The UI contract below governs the **CSS authoring output** (animation classes, token additions) and establishes the **design conventions** that all Phase 1–7 component implementations must follow.

## Spacing Scale

Source: `packages/ui/src/assets/tokens/index.css` — `--spacing: 0.25rem` (4px base unit). All Tailwind spacing utilities map to multiples of this unit.

| Token | Value | Usage in 0.5.0 components |
|-------|-------|--------------------------|
| xs | 4px (1 unit) | Icon gaps, inline padding within items |
| sm | 8px (2 units) | Compact element internal spacing (icon-to-label gap) |
| md | 16px (4 units) | Default element padding (button, input, menu item) |
| lg | 24px (6 units) | Section padding (dialog content area, popover body) |
| xl | 32px (8 units) | Layout gaps (dialog footer button row) |
| 2xl | 48px (12 units) | Major section breaks (not used in Phase 0) |
| 3xl | 64px (16 units) | Page-level spacing (not used in Phase 0) |

Exceptions: Touch targets for interactive controls (button, checkbox, radio, switch) must maintain minimum 44px height per WCAG 2.5.5. This is not a new token — enforce via `min-h-11` (44px at base spacing) in component Tailwind classes.

## Typography

Source: `packages/ui/src/assets/tokens/index.css` — global typography rules in `@layer base`. All values verified by direct file read.

| Role | Token / Size | Weight | Line Height | Usage |
|------|-------------|--------|-------------|-------|
| Body | `--text-base` / 16px | `--font-weight-normal` / 400 | 1.5 | Default text in component labels, descriptions, helper text |
| Label | `--text-sm` / 14px | `--font-weight-normal` / 400 | 1.5 | Input labels, menu item text, checkbox/radio labels |
| Heading | `--text-xl` / 20px | `--font-weight-semibold` / 600 | 1.2 | Dialog title, Popover title, Accordion header |
| Caption | `--text-2xs` / 10px | `--font-weight-normal` / 400 | 1.4 | Error text, helper text secondary, badge labels |

Active weights: **400 (normal)** and **600 (semibold)** — the two weights for all 0.5.0 components. Size contrast between 10px caption and 16px body is sufficient for hierarchy without a third weight. Weight 700 (bold) is reserved for the `.button` global class but not used in individual component classNames beyond that.

Font family: `var(--font-sans)` ("Quicksand") for all component text. `var(--font-serif)` ("League Spartan") is available as a token but is not used in component source.

## Color

Source: `packages/ui/src/assets/tokens/index.css` — `:root` (light) and `.dark` / `[data-theme="dark"]` blocks. All hex values below are light-theme values; dark-theme variants exist for every token.

| Role | Token | Light Value | Usage |
|------|-------|-------------|-------|
| Dominant surface (60%) | `--color-background` | `#f4f2ef` | Page background, outer wrappers |
| Secondary surface (30%) | `--color-surface-1` / `--color-surface-2` | `#ffffff` / `#f8f8f8` | Cards, popups, dialog panels, input backgrounds |
| Accent (10%) | `--color-primary` | `#21459b` | Focus rings, active indicators, primary button fill |
| Destructive | `--color-error` | `#cc5c5c` | Error states, destructive action buttons, error text |

**Accent reserved for (explicit list):**
- Primary button fill and hover state
- Focus ring on all interactive elements (`--color-primary-focus` / `#3b82f6`)
- Checked/active indicator in Checkbox, Radio, Switch, Slider thumb
- Active tab underline in Tabs component
- Slider track fill (filled portion)

**Color contract for animation CSS classes (PREP-03 deliverable):**
- Backdrop overlay: `--color-overlay` (`rgba(10,10,10,0.5)`) — applied via `.bct-dialog-backdrop`, `.bct-drawer-backdrop`, `.bct-alert-dialog-backdrop`
- Popup surfaces: `--color-surface-1` with `--shadow-lg` for elevation
- Border on popups: `--color-border` (`#e5e5e5` light / `#404040` dark)

**Token gap to resolve in Phase 0 (from RESEARCH.md open question):**
- `--color-border-muted` and `--color-border-muted-hover` are declared in `@theme` but have NO values in `:root` or `.dark` blocks. These tokens resolve to empty/invalid CSS. Phase 0 must either assign values or remove them from `@theme`. Recommended fix: add `--color-border-muted: #f0f0f0` and `--color-border-muted-hover: #e0e0e0` to the light `:root` block, with corresponding dark values.

- `--z-toast` is missing. Add `--z-toast: 120` to the `@theme` block alongside existing z-index tokens, above `--z-dialog-popup: 110`. (Source: RESEARCH.md token audit, open question 1)

## Copywriting Contract

Phase 0 produces planning documents and CSS, not user-facing UI. The copywriting contract below applies to the **API spec document** (`00-API-SPEC.md`) itself and to error/state copy that Phase 1–7 component implementations must use.

| Element | Copy | Applies To |
|---------|------|------------|
| Primary CTA label (component default) | "Confirm" for AlertDialog confirmButton; "Cancel" for cancelButton | AlertDialog component default props (implemented Phase 5) |
| Empty state (Select, Combobox no options) | "No options available" | Select, Combobox, Autocomplete empty list |
| Empty state (list filtered, no match) | "No results for [query]" | Combobox, Autocomplete filtered empty state |
| Error state (form field) | "[Field name] is required" / "[Field name] is invalid" | Field errorText prop default; component does not auto-generate — consumer provides copy |
| Destructive confirmation (AlertDialog) | Default `confirmLabel`: "Delete" / Default `cancelLabel`: "Cancel" | AlertDialog component default prop values |
| Toast variant labels | Success: "Success" / Error: "Error" / Warning: "Warning" / Info: "" | Toast title default when no title prop provided |

**Copy conventions for 0.5.0 component props:**
- All default prop strings use sentence case, not title case.
- Components do NOT generate error copy — they accept `errorText` as a prop and render it verbatim. Copywriting responsibility belongs to the consuming application.
- Placeholder text defaults (where applicable): `"Select..."` for Select, `"Search..."` for Combobox/Autocomplete.

### Missing Keyframes (add to `@theme` block)

| Keyframe | Definition |
|----------|------------|
| `slide-in-from-top` | `0% { transform: translateY(-100%); opacity: 0; }` → `100% { transform: translateY(0); opacity: 1; }` |
| `slide-out-to-top` | `0% { transform: translateY(0); opacity: 1; }` → `100% { transform: translateY(-100%); opacity: 0; }` |

## Component API Conventions (Design Contract Reference)

These conventions are the authoritative source for all Phase 1–7 component implementations. Pre-populated from CONTEXT.md decisions D-01 through D-10.

### classNames Slot Vocabulary (D-01, D-02)

Closed list — 20 canonical slots. No component may introduce a slot name outside this list.

`root` | `trigger` | `popup` | `backdrop` | `list` | `item` | `icon` | `indicator` | `label` | `description` | `helperText` | `errorText` | `header` | `footer` | `content` | `title` | `close` | `actions` | `cancelButton` | `confirmButton`

### Composition Stack (CONVENTIONS.md verified)

```
twMerge(clsx(baseStyles, conditionalStyles), classNames?.slot, className)
```

### Icon Props (D-09)

All icon props typed as `React.ReactNode`. Named override props: `triggerIcon`, `closeIcon`, `checkIcon`, `indicatorIcon`, `incrementIcon`, `decrementIcon`. Default: Lucide import. Passing `null` hides the icon. Passing any `ReactNode` replaces it.

### Animation Class Application Pattern

Apply named animation class as first argument to `twMerge` on the animated element — same pattern as 0.4.0 `dialog.tsx`:

```typescript
<BaseDialog.Popup
  className={twMerge("bct-dialog-modal", layoutStyles, classNames?.popup, className)}
/>
```

## Spacing Scale

Base unit: `--spacing: 0.25rem` (4px). All spacing expressed via Tailwind v4 multipliers of this base unit.

| Token | Value | Tailwind class | Usage |
|-------|-------|----------------|-------|
| xs | 4px | `gap-1` / `p-1` | Icon gaps, required-marker gap, Switch outer column gap (between track row and error text) |
| sm | 8px | `gap-2` / `p-2` | Inline element spacing, Field/Input/TextArea label-to-control gap, Switch label-to-track inline gap |
| md | 16px | `gap-4` / `p-4` | Default between form fields |
| lg | 24px | `gap-6` / `p-6` | Section or fieldset padding |
| xl | 32px | `gap-8` / `p-8` | Layout-level gaps (not used by Phase 2 components internally) |
| 2xl | 48px | `gap-12` | Major section breaks |
| 3xl | 64px | `gap-16` | Page-level spacing |

No spacing exceptions. All Phase 2 spacing values conform to the 4px grid.

Source: 0.4.0 `text-input.tsx`, `switch.tsx`, `text-area.tsx` reference implementations

## Typography

All Phase 2 form components use `--font-sans` (Quicksand). No heading or display roles appear inside these components.

| Role | Size token | px | Weight token | Weight | Line Height | Used by |
|------|------------|----|--------------|--------|-------------|---------|
| Input / textarea text | `text-base` | 16px | `font-normal` (400) | 400 | 1.5 | Input, TextArea — the native control element |
| Label | `text-sm` | 14px | `font-medium` (500) | 500 | 1.4 | Field.Label, Input label, TextArea label, Switch label row |
| Helper / description text | `text-sm` | 14px | `font-normal` (400) | 400 | 1.4 | helperText, description |
| Error / caption text | `text-sm` | 14px | `font-normal` (400) | 400 | 1.4 | errorText |
| Char count caption | `text-xs` | 12px | `font-normal` (400) | 400 | 1.4 | TextArea char count (optional) |

**Required-marker asterisk:** rendered as `text-error` color, same `text-sm` size as the label, separated by `gap-1` (`ml-1`).

Source: `index.css` @base typography rules; 0.4.0 `text-input.tsx` and `text-area.tsx` patterns; CONTEXT.md decisions

## Color

All colors expressed via BCT CSS variable tokens — no hex or rgb literals in component source (XCUT-01).

| Role | Token | Light value | Usage |
|------|-------|-------------|-------|
| Dominant surface (60%) | `--color-background` / `--color-surface-1` | #f4f2ef / #ffffff | Page background; input background |
| Secondary surface (30%) | `--color-surface-2` / `--color-surface-3` | #f8f8f8 / #e3dad3 | Disabled input background; fieldset background |
| Accent / interactive (10%) | `--color-primary` | #21459b | Focus ring, checked Switch track, pressed Toggle fill, active border |
| Destructive | `--color-error` | #cc5c5c | Error border, error text, error focus ring |

**Accent reserved for:**

- Switch track background when `data-checked`
- Toggle background when `data-pressed` (default and outline variants)
- Input and TextArea `border-color` on `:focus` (`--color-primary`)
- Input and TextArea focus ring (`--color-primary-focus`)
- Fieldset/Field `required` asterisk is `--color-error` (not accent — it is a semantic indicator)

**Color usage per component:**

| Input (disabled) | `bg-surface-1-disabled` | `border-border` (unchanged) | `text-typography-muted opacity-50` | none |

| Toggle (outline, unpressed) | transparent | `border-border` | `text-typography-primary` | same |

## classNames Slot Inventory

Each component exposes only slots from the canonical 20-slot vocabulary (Phase 0 API-SPEC Section 1).

| Component | Exported slots | Notes |
|-----------|---------------|-------|
| Field | `root`, `label`, `helperText`, `errorText` | `root` = Field.Root wrapper div |
| Fieldset | `root`, `label` | `root` = `<fieldset>` element; `label` = `<legend>` text |
| Form | `root` | `root` = Form.Root / `<form>` element |
| Input | `root`, `label`, `content`, `icon`, `helperText`, `errorText` | `root` = outer div; `content` = native `<input>` (D-06 resolution); `icon` = icon button wrapper |
| TextArea | `root`, `label`, `content`, `helperText`, `errorText` | `root` = Field.Root wrapper; `content` = native `<textarea>` (consistent with Input per D-06) |
| Switch | `root`, `label`, `description`, `indicator`, `errorText` | `root` = BaseSwitch.Root (pill/track); `indicator` = BaseSwitch.Thumb; outer wrapper div receives top-level `className` only (no named slot — CONTEXT.md D-specifics) |
| Toggle | `root` | `root` = BaseToggle.Root; single-element component |

**D-06 resolution (Claude's discretion):** The native `<input>` and `<textarea>` elements use the `content` slot — the closest canonical slot to "the main body of the control." This applies identically to both Input and TextArea for consistency.

Source: CONTEXT.md D-06, Phase 0 API-SPEC slot vocabulary

## Interaction & State Contracts

### Input / TextArea

| State | Visual |
|-------|--------|
| Default | `border-border` |
| Hover | `border-border-hover` |
| Focus | `border-primary ring-2 ring-primary-focus` |
| Error (any) | `border-error`; on focus `ring-2 ring-error` |
| Disabled | `bg-surface-1-disabled text-typography-muted opacity-50 cursor-not-allowed pointer-events-none` |
| Error + disabled | error border takes precedence |

Accessibility: `aria-invalid={!!error}`, `aria-describedby` wired to errorText id (priority) or helperText id (fallback).

### Switch

| State | Track | Thumb |
|-------|-------|-------|
| Unchecked | `bg-surface-2 border-border` | `translate-x-0.5` |
| Unchecked hover | `bg-surface-3` | unchanged |
| Checked (`data-checked`) | `bg-primary border-primary hover:bg-primary-hover` | `translate-x-5` |
| Focus visible | `ring-2 ring-primary-focus ring-offset-2` | — |
| Disabled | `opacity-50 cursor-not-allowed` | — |

Thumb animation: CSS `transition-transform duration-200 ease-in-out`.

### Toggle

Toggle uses Base UI's `data-pressed` attribute for pressed state styling.

| Variant | Unpressed | Pressed (`data-pressed`) |
|---------|-----------|--------------------------|
| default | transparent bg, no border | `bg-primary text-primary-on` |
| outline | transparent bg, `border border-border` | `bg-primary border-primary text-primary-on` |
| ghost | transparent bg, no border | `bg-surface-2 text-typography-primary` |

All variants: `hover:bg-surface-1-hover` when unpressed (except ghost which uses same rule).
All variants: `focus-visible:ring-2 focus-visible:ring-primary-focus ring-offset-2`.
Disabled: `opacity-50 cursor-not-allowed pointer-events-none`.

### Field

- `required` prop renders an asterisk `*` in `text-error` immediately after the label text, separated by `ml-1`.
- `errorText` is always rendered (not conditional on a `Field.Error` match) — Field is a layout wrapper, not a validation engine. Consumers wire error state themselves.
- `helperText` hidden when `errorText` is present (errorText takes visual priority).

### Fieldset

- Renders `<fieldset>` with `<legend>` child when `legend` prop is provided.
- Border: `border border-border rounded-lg` with `px-4 py-3` internal padding.
- `legend` text: `text-sm font-medium text-typography-primary px-1` (standard fieldset legend offset).

Source: CONTEXT.md decisions D-07 through D-10; 0.4.0 `switch.tsx`

## id Generation

Use `React.useId()` for stable SSR-safe id generation in Input and TextArea. Do NOT use `Math.random()` (breaks SSR hydration).

```typescript
const generatedId = React.useId()
const inputId = id ?? generatedId
```

## TextArea Retained Props (D-04 resolved)

The following props from 0.4.0 `text-area.tsx` are retained in 0.5.0 TextArea:

| Prop | Type | Default | Notes |
|------|------|---------|-------|
| `showCharCount` | `boolean` | `false` | Renders char count caption below textarea |

## Copywriting Contract

Phase 2 components are a component library — they do not contain app-level copy. The copywriting contract governs the fixed strings rendered by the components themselves.

| Element | Copy |
|---------|------|
| Required field marker | `*` (asterisk, rendered in error color) |
| Default icon button aria-label | `"Icon action"` (when `onIconClick` is defined); no aria-label when icon is decorative (`onIconClick` absent) |
| Char count format | `{count}` when no `maxLength`; `{count} / {maxLength}` when `maxLength` is set |
| Empty label (label prop omitted) | No label element rendered — not an error state, just omitted |

**Empty states:** These are layout/structural components. There is no empty state UI — if `children` is empty that is the consumer's responsibility.

**Error states:** Error text is consumer-supplied via `errorText` prop. Components do not generate error messages. No default error string exists.

**Destructive actions:** None in Phase 2. No confirmation dialogs, no delete actions.

Source: 0.4.0 reference implementations; CONTEXT.md phase boundary

## Animation Contract

| Component | Animation | Implementation |
|-----------|-----------|----------------|
| Switch thumb | Translate on check/uncheck | CSS `transition-transform duration-200 ease-in-out` via Tailwind class; no keyframe, no `index.css` class family needed |

All other Phase 2 components are static layout (no open/close, no overlay, no portal). No `bct-*` animation class families are required for this phase.

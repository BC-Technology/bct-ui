--- text-area.tsx (WR-01) ---

**Change 1: Fix charCount initial value.**

Find the line:
```tsx
const [charCount, setCharCount] = useState(0)
```

Replace with a lazy initializer that reads the pre-populated value:
```tsx
const [charCount, setCharCount] = useState(() => {
  const initial = props.defaultValue ?? props.value ?? ""
  return typeof initial === "string" ? initial.length : 0
})
```

Note: `props` refers to the destructured props available in scope at that point in the component. `defaultValue` and `value` are spread into `...props` in the current destructuring. To access them in the lazy initializer they must be destructured explicitly OR accessed from the `...props` rest object. In the current code, `onChange` is destructured and `...props` catches the rest including `defaultValue` and `value`. The lazy initializer reads `props.defaultValue ?? props.value` where `props` is the rest parameter. This is valid because the initializer is called during the render, after destructuring completes.

**Fallback text derivation helper** (carried from 0.4.0, placed inside the component as a local function or inline):
Derive initials from `alt` prop: split by space, take first char of each word, uppercase, slice to 2 chars.
Example: `alt="Jonas Blendstrup"` → `"JB"`.

**Component function:**
```typescript
export function Avatar({
  src,
  alt,
  fallback,
  fallbackIcon = <User />,
  size = "md",
  shape = "circle",
  className,
  classNames,
  ...props
}: AvatarProps) {
  const derivedInitials =
    alt != null
      ? alt
          .split(" ")
          .map((word) => word[0])
          .join("")
          .toUpperCase()
          .slice(0, 2)
      : null

  const fallbackContent = fallback ?? derivedInitials

  return (
    <BaseAvatar.Root
      className={twMerge(
        clsx(
          "relative inline-flex shrink-0 items-center justify-center overflow-hidden bg-surface-2",
          SIZE_STYLES[size],
          SHAPE_STYLES[shape],
        ),
        classNames?.root,
        className,
      )}
      {...props}
    >
      <BaseAvatar.Image
        src={src ?? ""}
        alt={alt ?? "Avatar"}
        className={twMerge("size-full object-cover", classNames?.image)}
      />
      <BaseAvatar.Fallback
        className={twMerge(
          "flex items-center justify-center font-medium text-typography-primary",
          classNames?.fallback,
        )}
      >
        {fallbackContent != null ? (
          fallbackContent
        ) : fallbackIcon != null ? (
          <span className={ICON_SIZE_STYLES[size]}>{fallbackIcon}</span>
        ) : null}
      </BaseAvatar.Fallback>
    </BaseAvatar.Root>
  )
}
```

**Critical implementation notes:**
1. Both `BaseAvatar.Image` and `BaseAvatar.Fallback` are ALWAYS rendered — Base UI controls visibility internally via `imageLoadingStatus`. Do NOT add `{src && <BaseAvatar.Image />}` conditional.
2. The `fallbackIcon` default `<User />` in destructuring — Biome will not flag this as an unused import because the default expression imports `User` which IS used. The import `import { User } from "lucide-react"` (not type import) is required.
3. `src ?? ""` passed to BaseAvatar.Image — if src is undefined, pass empty string so Base UI still mounts the Image element (it will fail to load and show Fallback, which is the correct behavior).

              classNames?.indicator,
            )}
          />
        </BaseMeter.Track>
      </BaseMeter.Root>
    </div>
  )
}

**Key implementation decisions (per 01-UI-SPEC.md §Visual differentiation and D-06):**

1. **Visible label:** `BaseMeter.Label` renders above the bar when `label` is provided. This is the key visual distinction from Progress — Meter ALWAYS shows label text visually; Progress uses label as aria-label only. The `BaseMeter.Label` element is rendered conditionally based on whether `label` prop is provided.
2. **Track height `h-3`:** 12px vs Progress's 8px — signals measurement vs task progress. Per 01-UI-SPEC.md visual differentiation rules.
3. **Track color `bg-surface-2`:** Slightly warmer than Progress's `bg-border`. Both exist in index.css. This differentiates the two components visually at a glance.
4. **Fill color `bg-primary`:** Single color per D-06 (no getSegmentStyle zones). Both Meter and Progress use bg-primary for fill — the track color and height differentiate them.
5. **Wrapper `<div>` with `flex-col gap-1`:** The label and meter track are wrapped in a flex column. This wrapper div accepts `className` — but since we're wrapping Root and Label in an outer div, the `className` prop from the consumer applies to `BaseMeter.Root` (the track container), not the outer wrapper. The `classNames.label` applies to `BaseMeter.Label`.
6. **`aria-label` on Root:** BaseMeter.Root gets `aria-label={label}` in addition to the visible Label element. This ensures the meter is accessible even if the visual label is hidden via classNames override.
7. **No indeterminate support:** No `value === null` handling. Meter's value prop is typed as `number` (required). If value is somehow undefined at runtime, Base UI will use its default.
8. **No `classNames.track` slot:** Track is internal. Only root (the track container), indicator, and label slots are exposed.

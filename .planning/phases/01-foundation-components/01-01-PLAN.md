  <action>
Append the following CSS block to the END of `packages/ui/src/assets/tokens/index.css`, after all existing content. Do not modify any existing CSS. Place it after the last existing animation/keyframe block.

The exact CSS to append:

```css

/* ─── BCT Progress animations ───────────────────────────────────────────────── */

@keyframes progress-indeterminate {
  0% {
    transform: translateX(-150%);
  }
  100% {
    transform: translateX(400%);
  }
}

.bct-progress-indeterminate[data-indeterminate] {
  animation: progress-indeterminate 1.5s cubic-bezier(0.4, 0, 0.6, 1) infinite;
  width: 35%;
}
```

Key decisions (per 01-UI-SPEC.md §Animation Contract and 01-RESEARCH.md §Pattern 6):
- The selector targets `.bct-progress-indeterminate[data-indeterminate]` — the Progress Indicator element gets class `bct-progress-indeterminate` applied in the component, and Base UI adds `[data-indeterminate]` to it when `value === null`
- `width: 35%` — visible enough for motion; standard indeterminate convention
- Duration `1.5s` with `cubic-bezier(0.4, 0, 0.6, 1)` matches BCT's ease-in-out feel
- `infinite` — no `fill-mode` needed for infinite loops
- `translateX(-150%)` to `translateX(400%)` — wider sweep than a naive 0-100% so the bar enters and exits smoothly from outside the track bounds
